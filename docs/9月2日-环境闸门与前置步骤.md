## 1. 为什么这条任务会失败

任务已经选了测试环境，设备上也很可能已经切过。失败原因不是「没切」，是闸门把 **登录页看不出环境** 写成了 **环境和本趟不一致**。

当时落库：

```json
env_align: {
  "wanted": "test", "label": "测试",
  "observed": "unknown", "matched": false, "switched": false, "ok": false,
  "reason": "当前是造好物移动端的登录页面，未出现任何环境标识、角标或环境相关的文案信息，无法判断当前环境。"
}
```

两条用例都没有 trace。闸门在领用例之前就把整单判死。

叠加了三件事：

| 事实 | 旧行为 |
|------|--------|
| 造好物环境标识在「我的」连点头像 / 调试面板，登录页没有角标 | `inspect_env` 正确返回 `unknown` |
| `align_device_env` 要求 `env_matches(observed, wanted)` 才 `ok` | `unknown` 的 canon 是空串，匹配失败 → 整单前置不足 |
| 切环境走独立 `AgentExecutor(case_id=__env_align__)` | 登录页 +「不要登录」容易放弃；即便切成功，切完仍停在登录页，第二次 inspect 还是 `unknown`，照样杀单。`switched=false` 说明这次连 `signal_done` 都没有 |

**unknown 只表示这一屏看不出来，不是环境不对。** 登录页既不能证明是测试，也不能证明是正式。

## 2. 为什么时间线上没有「切换环境」

环境对齐发生在 `_next_unit` **之前**，`run_id=batch`、`case_id=__env_align__`。步骤进不了 `cr-xxx::用例 id`。

前端 `emptyTree` 的前置只来自用例原文（已登录、已打开 App、后台开关）。没有「切换到测试环境」这一行。`matchPrepTask` 还把 `inspect_env` / `env_align` 误挂到登录行上。

所以即使用户认为已经切过，详情页也看不到观察环境、切换环境的入口。

## 4. 闸门语义

`env_conflicts(observed, wanted)`：两边都识别成 key 且不是同一个才冲突。`unknown` / 空串不算冲突。

`align_device_env` 结果：

| 观察 | 结果 |
|------|------|
| 已是本趟环境 | `ok=true`，`env_align` skipped「无需切换」 |
| 能看出是另一个环境 | `ok=false`，整单（或该设备）前置不足 |
| 看不出（登录页无角标） | `ok=true`，`unconfirmed=true`，reason 追加「未当作与本趟环境不一致」 |

登录页仍会尝试切一次（想到能看见环境的页再确认），切完仍 `unknown` **不再杀单**。切环境放弃不再记成 `session_align` FAIL，由外层 inspect 决定 `ok`。

环境对齐改到 `AgentExecutor.run()`：`_emit("start")` 之后、session 闸门之前调 `_gate_env_before_loop()`。`switch_fn` 走同一 executor 的 `_run_session_actions("env")`。本趟已有 `ctx.env_fact.ok` 则合成 skipped「沿用本趟环境」。

`case_runner` 开跑前只 `attach_run_env` + 需要时 `provision_device`，**不再**在领用例前 `align_device_env` + `_fail_remaining_prep`。真冲突时第一条失败后再收剩余用例。`failure_category=prep_insufficient` 覆盖类走前置不足，不当产品红。

## 5. 步骤入口（前端 MiniOrange）

时间线前置最前面注入 `p-env`「切换到{label}环境」，用任务上的 `envAlign` 盖章：

- `ok=false` → `PREP.UNMET.env`（未就绪）
- `ok=true`（含 unconfirmed）→ `PREP.OK.env`
- Web / `skipped=url_distinguishes` → 不插入

`inspect_env` / `env_align` 只挂这一行，不再进登录分支。观察 → 切换 → 连点/点击（仍算前置）→ 再观察。

用例原文若已写「测试环境」等，与 `p-env` 合并，不重复两行。
